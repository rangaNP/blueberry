# Changelog

All notable changes to this project are documented in this file.

## [1.0.0] - 2026-03-17

### Added

- Initial Blueberry dark theme release
- Full UI color set for editor, side bar, tabs, title bar, status bar, panel, and terminal
- Syntax token palette with blueberry, purple, mint, and rose accents
- Targeted property semantic highlighting support for consistent property coloring

### Improved

- Better readability for object keys and member properties in JavaScript/TypeScript
- Reduced low-contrast whites in code identifiers
